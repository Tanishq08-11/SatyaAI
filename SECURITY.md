# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

We take security and misinformation integrity seriously. If you discover a security vulnerability or exploit within SATYA AI, please **do not** open a public issue.

Instead, please send an email with details and reproduction steps to:
- Contact: tanishq.1251050254@vit.edu

Include the following information:
1. Type of issue (e.g., authentication bypass, injection, secret exposure).
2. Step-by-step instructions or minimal script to reproduce the vulnerability.
3. Affected components or endpoints.

We will acknowledge receipt within 48 hours and work with you to remediate and publish a patch.
